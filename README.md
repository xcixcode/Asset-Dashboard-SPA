# Asset-Dashboard-SPA

**연령대별 가상 고객의 자산, 소비, 신용 현황을 시각화하고 인터랙티브하게 관리할 수 있는 클라이언트 사이드 웹 대시보드 애플리케이션**

---

## 개요

본 프로젝트 **Asset-Dashboard-SPA**는 **React 및 Tailwind CSS, Recharts UMD 라이브러리**를 활용해 **연령대별 금융 자산과 소비 패턴을 한눈에 파악**할 수 있도록 제작된 **단일 페이지 웹 애플리케이션**입니다.  
사용자가 **실시간 가상 데이터 생성 및 인터랙티브 대시보드 조작**을 통해 **맞춤형 금융 지표 및 상세 성향 분석**을 얻을 수 있습니다.  
별도의 서버 환경이나 빌드 과정 없이 **웹 브라우저**에서 클라이언트 사이드(Client-side)로 작동하여 단순하고 빠르게 실행 가능합니다.  

---

## 기술 스택

- **HTML5** - 페이지 구조 및 콘텐츠 구성
- **CSS3 (Tailwind CSS 3.4.17)** - 스타일링, 레이아웃, 반응형 디자인
- **JavaScript (Vanilla / ES6+)** - 핵심 로직 및 UI 상호작용
- **React 18.3.1 (UMD) & Babel** - 컴포넌트 기반 UI 구축 및 브라우저 내 JSX 컴파일
- **Recharts 2.12.7** - 연령대별 예적금/대출 비교 및 소비 카테고리 분포 차트 시각화
- **Lucide React** - 직관적인 UI 아이콘 렌더링
- **RandomUser API** - 가상 고객 프로필 생성을 위한 외부 데이터 연동 (네트워크 오류 시 로컬 대체 데이터 활용)

---

## 주요 기능

- **실시간 가상 고객 생성 및 연동**: RandomUser API 기반 나이/지역 정보를 바탕으로 40명의 가상 고객 금융 데이터(예적금, 대출, 투자, 소비) 자동 구축
- **대시보드 자산 시각화**: 평균 순자산, 평균 신용점수, 주요 소비 카테고리 요약 및 연령대별 예적금/대출 비교 바 차트·파이 차트 제공
- **인터랙티브 고객 리스트 및 검색**: 이름 검색 기능 및 연령대별(20대, 30대, 40대, 50대 이상) 필터링 지원
- **상세 고객 모달(Modal)**: 고객 선택 시 순자산, 신용 점수 게이지, 자산 구성 비율, 월평균 소비 및 금융 성향 상세 분석 제공
- **반응형 UI 지원**: PC 좌측 내비게이션 바와 모바일 하단 탭 바를 지원하여 다양한 화면 크기에 유연하게 대응

## 설치 및 실행

### GitHub Pages

https://xcixcode.github.io/Asset-Dashboard-SPA/

### 로컬에서 실행

1. 저장소를 클론하거나 파일을 다운로드합니다.
2. `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)에서 엽니다.
3. 별도의 **서버 설정이나 패키지 설치 없이** 바로 실행됩니다.
   * *(인터넷 연결 필요: Tailwind, React, Recharts 등 외부 CDN 스크립트 로드)*
